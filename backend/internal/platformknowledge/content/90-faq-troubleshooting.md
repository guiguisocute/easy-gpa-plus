# 常见问题与故障排查

## 在哪里交材料？

学生从左侧导航进入“提交材料”。提交完成后到“我的提交”查看状态，不要在 Agent 对话框里发送材料代替正式申报。

## 怎么交材料？

选择分类和项目，填写申报信息，上传佐证，保存草稿并核对，最后点击正式提交。AI 整理只能生成候选草稿，不能自动提交。

## 为什么没有按钮或按钮不可用？

常见原因包括当前角色或视角不对应、时间窗口未开放或已关闭、记录已封存、任务已完成或重新分配、方案未发布、平台能力开关关闭。刷新页面后仍无法操作，应把当前页面、记录编号和提示信息交给班级管理员；不要让 Agent 猜测实时状态。

## 上传失败怎么办？

确认文件仍在允许的大小和格式内，网络连接稳定，并等待上一份文件完成。文件显示“上传中”时不要重复提交；显示转换失败时，班管可在知识库查看错误并重处理。持续失败时记录文件类型、大小和页面提示联系管理员。

## 为什么 Agent 不可用或不引用资料？

Agent 需要平台 AI、知识库、知识外发和本班第三方处理授权同时开启，并受每日额度限制。没有引用可能是资料没有命中、文件仍在转换、文档未对当前角色发布或模型没有生成有效引用。涉及规则和状态时，应要求它检索资料或联系管理员确认。

## Agent 的回答能直接改变系统吗？

不能。Agent 的建议最多形成草稿或预填；提交、审核、方案发布、仲裁、结算和导出仍需在对应页面由有权限的用户确认。知识文件也不能改变系统权限、租户隔离、隐私或 AI 授权规则。
