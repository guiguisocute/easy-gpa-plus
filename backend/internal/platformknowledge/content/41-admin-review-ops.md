# 分发、仲裁与专业素质分

“分发”用于试算审核任务、检查冲突并按确定的随机种子执行分配。正式运行前应查看参与审核人、负载和冲突提示；重新分配和交接都会留下记录。

“仲裁与申诉”集中处理双人审核冲突、分类问题、学生申诉和需要管理员终裁的异议。管理员应查看两侧证据和规则快照后作出决定，Agent 只能帮助查资料或整理草稿，不能自动终裁。

“处理历史”可从班级管理侧栏或仲裁台右上角进入，按处理类型、学生、关键词和日期筛选当前班管本人在本班签发的记录。展开后可回看佐证、原审核意见和处理理由；当时裁定分保留原值，后续申诉或强制驳回不会覆盖旧记录。此页只供回溯。

班管不能终裁自己的事项。请在成员管理中从已注册且已启用的综测小组成员里任命一名“副班管”，由其在综测小组身份下的“副班管仲裁”页面处理班管本人的冲突、申诉、小组提案和举报。每班最多一名副班管；可撤销或换人，停用账号或转出综测小组也会自动撤销任命。重置密码保留任命，重新设置密码后即可继续履职。

“专业素质分”用于导入成绩数据并参与最终合成。导入后应核对学号匹配、缺失记录和异常值。具体合成方式由当前方案和结算器决定，不由平台知识文件或模型重新计算规则。
