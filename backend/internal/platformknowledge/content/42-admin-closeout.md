# 知识、授权、结算、导出与审计

“知识库”由班级管理员维护本班规则文件。文件上传后经过安全转换，状态为可检索或部分可检索时 Agent 才能读取正文。不同可见范围决定学生、综测小组和班管能否检索；运维超管不能查看这些班级文件。

启用知识 Agent 前，班级必须确认第三方处理授权，平台也必须开启 AI、知识库和知识外发。撤销授权后新的问答和 OCR 会停止；平台产品帮助不会绕过授权。

封存完成后，管理员根据门槛处理遗留问题并运行结算。结算和评分由后端规则执行，模型不参与出分。导出中心生成汇总、明细或归档文件；任务完成前应保留页面并稍后刷新状态。

“审计日志”记录包含读写操作的班级资源轨迹，供班管核查。运维平台审计只记录平台配置操作，不提供学生业务正文。
