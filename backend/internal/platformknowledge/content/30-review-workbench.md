# 综测小组任务与审核工作台

“待办任务”列出分配给当前审核人的材料和申诉任务。审核人只能处理系统分配且仍处于可处理状态的任务，不能通过修改地址或向 Agent 描述任务编号取得其他人的任务。

进入“审核工作台”后，结合申报内容、佐证、规则快照和当前方案作出结论。系统采用多人审核和冲突处理机制时，每位审核人独立提交自己的判断；在允许盲审的阶段，不应寻找或泄露另一位审核人的结论。

Agent 可以帮助查找班级规则、解释页面或形成审核预填，但不会替审核人提交正式结论。最终决定必须由本人在工作台核对后提交，并进入审计记录。

任务消失或按钮不可用通常表示任务已完成、被重新分配、流程窗口关闭或状态已经变化，应刷新任务列表并以页面结果为准。
