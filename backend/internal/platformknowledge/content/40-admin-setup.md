# 班级方案、窗口与成员管理

## 方案

“方案编辑器”维护分类、项目和计分规则。草稿方案可反复校验，发布后形成版本；学生申报和审核应对应明确的方案版本。修改方案前先确认是否会影响已有提交、审核或结算，不用 Agent 的自然语言回答替代方案校验。

## 时间窗口与功能开关

“时间窗口”设置材料开放、封存截止、全系统封锁、公示起止时间，以及审核确认时限和评优设置。“功能开关”独立控制提交、修改、审核、申诉、仲裁、匿名举报和结算闸门。修改这些运行设置不会发布新方案版本。

公示窗口默认不设置。班管填写公示起止时间并保存后，本班普通成员在公示期间可通过举报台展开计分条目，预览和下载已公开的佐证原件。原有分数、公开理由和匿名计分轨迹仍沿用举报台；公示不会开启匿名举报提交权限。未提交材料、未公开审核备注和匿名举报附件不公示。公示结束后普通成员不再获得原件下载地址，学生本人、小组及班管原有业务权限保留。

## 班级成员

“班级成员”用于导入预置名单、任命或调整角色、停用账号和解封。角色变更影响后续权限，但不会抹除此前以原角色产生的审计记录。视角切换只是页面预览，不能替代真实角色调整。
